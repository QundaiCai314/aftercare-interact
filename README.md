# aftercare-interact 1.0.0

售后页面推进与陪同 Skill：将当前一个步骤转换为简短说明、高亮引用或单步动作提案，支持 self、guided、auto 三种模式。

## 下载与使用

- `aftercare-interact-1.0.0.zip`：可加载 Skill 包，解压后将 aftercare-interact 文件夹放入技能目录。
- `aftercare-interact-1.0.0-full.zip`：完整工程，包含接口样例、校验器、合成测试、隔离浏览器装置、运行结果及契约提案。
- `测试报告.md`、`契约修订提案.md`：验证范围、消费者影响与当前限制。
- `SHA256SUMS.json`：上传文件摘要。

## 已实现与验证

Skill 只生成计划，不点击、填写、选文件或发送，也不选择业务方案或生成执行授权。实际操作须经过宿主执行层，每次最多一个最小动作，页面变化后重新观察。

111项离线检查通过；候选联合Schema另有7项检查。独立模型16例首轮与5例定向回归共21份输出已保存，结构及身份校验通过，不把结构正确当作业务全部通过。

补全后的隔离合成商城在真实 Tabbit 浏览器完成47项检查，包括导航、自动保存、即时上传、提交及授权/失效/重复动作拦截。13组实际浏览器回执及新观察完成中央核对接口校验。测试计划与上下游消费者是明确标注的替身，不声称生产全链已接通。

Python 校验依赖 jsonschema。浏览器装置还需现有 Tabbit 稳定启动器；完整工程内 `browser-tests/run.ps1` 是已验证复跑入口。装置只绑定本机，不连接真实商城。两次截图均超时，保留了实际DOM和几何检查记录，不声称完成截图人工审阅。

中央契约保持1.0.0，上游正式确认绑定仍存在缺口。生产授权、真实平台适配、跨服务事务与完整崩溃恢复未实现；本包不自动安装或部署运行时。
